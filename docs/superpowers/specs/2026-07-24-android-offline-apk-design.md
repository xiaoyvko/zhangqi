# 账期安卓离线 APK 设计

## 目标

把现有“账期”React PWA 打包为可独立安装的安卓 APK，供用户本人和朋友在中国大陆直接安装使用。APK 的核心记账、固定账单、头像和提醒功能不依赖网站或网络。

## 用户与使用方式

- 第一阶段面向用户本人和少量朋友，通过聊天工具直接分享 APK。
- 安装后从空账本开始，不迁移网页版测试数据。
- 每台手机的数据相互独立，不提供账号、多设备同步或朋友间流水共享。
- 保留现有网页版，APK 与网页版并行存在，二者数据不互通。

## 技术方案

使用 Capacitor 将现有 Vite/React 应用封装为安卓原生容器：

- Web 界面和静态资源打包进 APK，启动时从应用内部加载。
- 使用 Capacitor Local Notifications 提供安卓系统级本地提醒。
- 使用现有浏览器存储接口保存账单、流水、资料和提醒设置；这些数据位于 APK 自己的应用存储空间。
- 不把线上 `chatgpt.site` 地址作为 APK 的运行入口，离线状态下也能完整启动。

不采用网页壳方案，因为它仍依赖境外网址；不进行完全原生重写，因为现有 React 功能已经满足当前需求。

## 应用身份与兼容性

- 应用显示名称：`账期`
- Android 包名：`com.zhangqi.billreminder`
- 第一版版本号：`1.0.0`
- 最低安卓版本：Android 8.0（API 26）
- 目标安卓版本：使用构建时官方稳定 SDK 的目标版本
- 输出通用 APK，适配常见 ARM64 安卓手机

## 本地数据

继续使用现有 `zhangqi-finance-v2` 数据结构，并为提醒设置增加以下字段：

```js
{
  reminderSettings: {
    enabled: true,
    daysBefore: 3,
    time: "09:00"
  }
}
```

每个固定账单增加：

```js
{
  reminderEnabled: true
}
```

兼容规则：

- 缺少 `reminderSettings` 时使用默认值：开启、提前 3 天、09:00。
- 旧账单缺少 `reminderEnabled` 时视为开启。
- 正常覆盖安装新版时保留应用数据。
- 卸载 APK 或在系统设置中清除应用数据会删除本地账本，界面中必须明确提示。

## 提醒行为

### 默认规则

- 全局提醒默认开启。
- 默认在账单到期前 3 天的上午 09:00 提醒。
- 用户可以在“我的—提醒设置”中选择提前 0、1、3 或 7 天，并修改通知时间。
- 每个固定账单可以单独关闭提醒。

### 调度规则

- 新增、修改或删除固定账单后，重新计算相关本地通知。
- 修改全局提醒设置后，重新调度所有账单通知。
- 应用启动或恢复到前台时校准未来通知，避免账单变化后出现过期提醒。
- 只为未来的提醒时间安排通知；已经错过的时间不补发。
- 通知标题显示账单名称，正文包含金额和到期日期。
- 使用稳定、可重复生成的通知 ID，防止同一账单产生重复通知。

### 权限和失败处理

- Android 13 及以上首次启用提醒时请求通知权限。
- 用户拒绝权限后，应用仍可正常记账，并在提醒设置页显示“系统通知未开启”。
- 调度失败不影响账单保存；界面显示简短提示，并允许用户重新开启提醒。

## 界面改动

### 提醒设置

在“我的”页面中让现有“提醒偏好”入口可点击，进入设置面板：

- 总开关
- 提前天数：当天、1 天、3 天、7 天
- 提醒时间
- 当前系统通知权限状态

### 固定账单

在新增和编辑固定账单的表单中加入“到期提醒”开关，默认开启。

### APK 环境

- APK 中隐藏或替换仅适用于浏览器 PWA 的安装提示。
- 头像继续支持从手机相册选择并压缩。
- 所有功能保持现有简约移动端视觉风格。

## 签名与升级

- 生成专用的安卓发布签名密钥，用于第一版和后续更新。
- 密钥、密码和本地签名配置不提交到 Git，也不上传到公开 Sites 仓库。
- 保存一份可恢复的本地签名材料和说明；后续必须使用同一签名才能覆盖安装并保留数据。
- 交付签名后的 release APK，而不是仅用于调试的 APK。

## 构建环境

电脑当前没有 Java 和 Android SDK。实现阶段使用免费的官方安卓构建组件：

- JDK 21（Capacitor 8 安卓工程要求）
- Android SDK command-line tools
- 对应的 platform-tools、build-tools 和 Android platform
- Gradle Wrapper

优先安装构建所需的最小组件，不要求用户安装完整 Android Studio。

## 测试与验收

### 自动测试

- 提醒默认值和旧数据兼容。
- 提醒时间计算覆盖提前 0、1、3、7 天。
- 过去时间不调度。
- 通知 ID 对同一账单稳定、不同账单不冲突。
- 新增、修改、删除账单触发正确的重新调度。
- 全局关闭或单个账单关闭时取消对应通知。

- Vite 生产构建成功。
- 网页版继续能够正常使用，不因 Capacitor 集成而损坏。

### 安卓验收

- 生成签名 release APK。
- APK 可以安装并从桌面图标启动。
- 断网后仍能新增收入、支出和固定账单。
- 关闭并重新打开应用后数据仍存在。
- 可以选择相册照片作为头像。
