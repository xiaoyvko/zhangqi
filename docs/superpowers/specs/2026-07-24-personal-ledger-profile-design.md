# 账期：个人资料与日常记账功能设计

日期：2026-07-24

## 目标

在现有订阅与固定账单提醒器基础上，增加个人资料和私人日常记账能力，让用户既能管理周期性支出，也能记录每天的收入与支出。

本轮功能面向单人、本机使用。日常流水不与朋友共享，不增加账号、服务器或云同步。

## 产品结构

底部导航调整为五个入口：

1. 首页
2. 账单
3. 中央快捷操作按钮
4. 明细
5. 我的

中央快捷操作按钮打开操作菜单，提供：

- 记支出
- 记收入
- 添加固定账单

原有订阅、固定账单、提醒和朋友共享功能继续保留。朋友共享入口合并到“账单”页面，不进入私人日常流水。

## 页面设计

### 首页

首页展示：

- 本月收入
- 本月支出
- 本月结余
- 未来七天待付账单
- 最近日常流水
- 即将扣款的固定账单

所有金额由本地流水和固定账单数据实时计算。新增、修改或删除记录后，首页立即更新。

### 账单

账单页面集中管理：

- 订阅
- 房租等固定账单
- 朋友共享账单
- 到期和扣款日期

日常收入和支出不出现在朋友共享区域。

### 记账表单

收入和支出使用同一套表单，包含：

- 类型：收入或支出
- 金额：必填且必须大于 0
- 说明：可选
- 分类：必选
- 日期：默认今天，可修改

说明为空时，保存后使用分类名称作为默认说明。

默认支出分类：

- 餐饮
- 交通
- 购物
- 娱乐
- 住房
- 医疗
- 学习
- 其他

默认收入分类：

- 工资
- 奖金
- 兼职
- 报销
- 朋友还款
- 其他

用户可以编辑或删除已保存的流水。

### 明细

明细页面提供三个视图：

#### 流水

- 按日期倒序排列。
- 同一天的记录分组展示。
- 每组显示当日收入、支出和净额。
- 点击记录进入编辑状态。

#### 日历

- 每个日期显示是否存在收入或支出。
- 点击日期显示当日全部流水。
- 月份切换后同步更新当月汇总。

#### 统计

- 展示当月收入、支出和结余。
- 展示支出分类占比。
- 展示收入分类占比。
- 统计结果只基于日常流水，不把固定账单重复计入；固定账单实际付款后可手动记为日常支出。

### 我的

个人资料包含：

- 可修改的显示名称
- 从手机相册选择的头像

头像处理流程：

1. 用户从相册选择图片。
2. 应用校验图片类型。
3. 图片在手机端裁剪为正方形并压缩。
4. 压缩后的头像保存到本机。
5. 首页和“我的”页面立即显示新头像与名称。

“我的”页面继续承载提醒偏好、设备信息和本地数据说明。

## 数据设计

### 个人资料

```text
Profile
- name
- avatarData
- updatedAt
```

### 日常流水

```text
Transaction
- id
- type: income | expense
- amount
- description
- category
- date
- createdAt
- updatedAt
```

金额以数值保存，展示时统一格式化为人民币。日期使用本地日期字符串，避免跨时区导致账目显示到前一天或后一天。

### 本地存储

- 个人资料、流水和固定账单保存在当前设备。
- 头像在保存前限制尺寸并压缩，避免超过浏览器存储容量。
- 应用启动时读取本地数据；数据格式异常时保留可读取部分并提示用户。
- 卸载应用或清除浏览器数据可能删除账目，应用在“我的”页面明确提示这一点。

本轮不实现账号、云数据库、多设备同步和数据共享。

## 交互与异常处理

- 金额为空、不是数字或小于等于 0 时禁止保存并显示提示。
- 未选择分类时禁止保存。
- 图片格式不支持、图片读取失败或压缩失败时保留原头像并显示提示。
- 本地存储空间不足或写入失败时，不关闭表单，保留用户已填写内容并显示错误。
- 删除流水需要二次确认。
- 空流水、空日历日期和无统计数据均提供明确空状态。

## 验证范围

功能完成后验证：

1. 新增收入和支出。
2. 编辑与删除流水。
3. 默认说明和分类校验。
4. 按日分组及跨月份日期计算。
5. 月度收入、支出、结余和分类汇总。
6. 流水、日历和统计视图切换。
7. 姓名修改后在首页和“我的”页面同步显示。
8. 手机相册头像选择、压缩、保存和刷新后恢复。
9. 页面刷新及应用重新打开后数据保留。
10. 原有固定账单、提醒与共享账单功能没有回归问题。
11. 安卓手机尺寸下的表单、导航和弹层可正常操作。

## 暂不包含

- 账号注册或登录
- 多设备同步
- 日常流水共享
- 银行卡或支付平台自动导入
- 预算管理
- 数据导出与导入
- 多币种
