# 账期 Android 安装说明

安装包位于 `release/账期-1.0.0.apk`。把它发送到 Android 手机后，按下面步骤安装：

1. 在手机的文件管理器或浏览器中找到 `账期-1.0.0.apk`。
2. 若系统提示，请允许当前文件管理器或浏览器安装未知来源的应用。
3. 点击安装包并完成安装，然后打开“账期”。
4. 使用提醒功能时，请在系统提示后允许通知权限；否则手机无法显示账单提醒。

## 更新时请保留数据

以后收到新版本时，直接打开新 APK 并安装到现有“账期”应用上方即可。**如需保留本机账单、头像和提醒设置，请不要在更新前卸载旧版应用。** 卸载应用会清除本机保存的数据。
